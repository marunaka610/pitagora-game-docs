3.3 共鳴現象（Resonance Phenomenon）¶

目的¶

周期的な外力を受ける振動系を操作し、外力の周波数と系の固有振動数の関係によって応答振幅が変化することを観察します。共鳴付近で振幅が大きくなることと、減衰によって応答が抑えられることを比較可能にします。

物理モデル¶

モデルの基本案は、外力を受ける1自由度の減衰振動系です。

\[ m\ddot{x} + c\dot{x} + kx = F_0\sin(2\pi f t) \]

ここで、m は質量、c は減衰係数、k はばね定数、F₀ は外力の振幅、f は外力の周波数、x は平衡位置からの変位です。減衰が小さいとき、固有振動数付近で応答振幅が大きくなる関係を可視化します。採用するモデルと式は実装前に確認し、異なる系を用いる場合は本節を更新します。

表示¶

  • 振動体の変位を平衡位置とともに表示し、正負の変位と振動周期を読み取れるようにします。
  • 時間経過に対する変位を表示し、外力の周期と系の応答を比較できるようにします。
  • 外力の周波数を固有振動数の前後で変化させたとき、応答振幅がどう変化するかを確認できる表示を設けます。
  • 減衰を比較できるようにし、共鳴時の振幅が無制限に増えるかのような表示を避けます。

操作と期待結果¶

操作パネルでは、少なくとも外力の周波数と減衰の変更を基本操作とします。物理モデルを採用する場合は、質量、ばね定数、外力の振幅も設定対象とし、変更した値と単位を表示します。

  1. 初期条件とパラメーターを設定して振動を開始します。
  2. 外力の周波数を変えると、外力に対する変位の時間応答が更新されます。
  3. 共鳴付近と離れた周波数での応答を比較します。
  4. 減衰を増やすと共鳴付近の最大振幅が小さくなることを確認します。
  5. リセット操作では、振動状態と設定値をそれぞれ定義された初期状態へ戻します。

減衰係数は正の範囲に制限し、共鳴時の振幅が時間とともに無制限に増えないモデルにします。数値計算が不安定になる入力を許可しないよう、その他のパラメーターにも範囲を設けます。停止・再開、時間軸の扱い、入力範囲外の値をどう扱うかは実装前に確定します。

確認項目¶

  • 減衰振動系のモデル、初期条件、単位系
  • 各パラメーターの範囲・初期値と、操作中の再計算方法
  • 変位表示、周波数応答表示、共鳴を示す補助表示の具体的な形式
  • 停止・再開・リセット時にパラメーター値を保持するか
