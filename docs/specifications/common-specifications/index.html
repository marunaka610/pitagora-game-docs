4・5. 共通仕様¶

本ページは、ゲーム内の複数画面・ステージで共通して適用する仕様をまとめます。画面固有の仕様と矛盾する場合は、共通の操作・表示ルールを保ったうえで、固有ページに例外と理由を明記します。

表示と操作¶

  • 画面ごとにタイトルや現在の状態を示し、プレイヤーが現在地を把握できるようにします。
  • ボタンや操作対象は、実行できる操作が分かる表示にします。
  • 操作後は、処理中・成功・未達成・エラーなど、結果に応じた状態を示します。
  • 無効な操作や連続入力で、画面や進行状態が不整合にならないようにします。
  • 操作に必要な説明は、プレイ開始前または操作対象の近くに提示します。

画面遷移¶

  • 遷移の前後で、プレイヤーが選択したステージや操作結果を意図せず失わないようにします。
  • 破棄されるプレイ状態がある場合は、必要に応じて遷移前に確認します。
  • 戻る操作を提供する場合は、戻り先と状態の扱いを画面間で一貫させます。
  • 連続入力により同じ遷移が重複して実行されないようにします。

エラーと復旧¶

  • 処理に失敗した場合は、プレイヤーが状況を理解し、再試行または安全な画面へ戻れる案内を行います。
  • 内部エラーの詳細や機密情報を、そのままプレイヤー向け画面に表示しません。
  • 一時的なエラーで再試行できる場合は、再試行操作を明確にします。
  • 復旧できない場合は、プレイ状態や進行状況を不正な状態で更新しません。

進行状況・データ¶

進行状況を保存する場合は、保存対象、保存のタイミング、読み込み失敗時の挙動、リセット方法を定義します。保存を実装するまでは、再訪時にもデータが保持されると案内しません。

品質・対応環境¶

  • 操作説明や状態表示は、色だけに依存せず文字・形状などでも判別できるようにします。
  • 文字や操作対象は、対応する画面サイズで読めて操作できることを確認します。
  • 対応端末・ブラウザー、性能目標、アクセシビリティ対応範囲は、リリース対象に合わせて決定します。

要確認

  • 対応端末・ブラウザー・画面サイズ
  • 保存方式、保存対象、リセット方法
  • 性能目標、アクセシビリティ対応範囲
  • エラー時の表示文言と再試行可能な操作
