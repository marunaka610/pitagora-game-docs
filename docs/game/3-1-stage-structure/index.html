3.1 ステージ構成¶

目的¶

ステージは、プレイヤーが課題に挑戦する単位です。ステージごとに開始状態、達成条件、操作対象を定義し、プレイ開始時に必要な情報を提示します。

ステージに定義する情報¶

各ステージの仕様には、少なくとも次を記載します。

項目 内容
識別子 ステージを一意に識別する値
表示名 ステージ選択やプレイ中に表示する名前
課題 プレイヤーが達成すべきこと
初期状態 開始時の盤面・仕掛けの状態
操作対象 プレイヤーが操作できる要素と操作方法
達成条件 クリアと判定する条件
再挑戦条件 初期状態に戻す範囲

ステージ選択¶

ステージ選択画面を設ける場合、プレイヤーが各ステージを識別し、選択可能かどうかを判断できる表示にします。未実装・ロック中のステージを選択可能なステージと誤認させないようにします。

ステージの順序、解放条件、ロック表示、一覧のページ分割は、採用するステージ数と進行ルールに合わせて定めます。

初期状態と再現性¶

  • 同じステージを開始または再挑戦したときは、定義された同じ初期状態から始めます。
  • 前回の試行中に行った操作は、再挑戦時の初期状態に持ち越しません。
  • ステージ更新時は、既存のクリア状況を保持するかどうかを明示してから変更します。

要確認

  • ステージ数、名称、公開順
  • ステージの解放条件と進行順の制約
  • ステージ別の難易度・操作可能要素
