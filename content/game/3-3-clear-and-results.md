# 3.3 クリアと結果

## クリア判定

- ステージごとに定義された達成条件を満たした時点でクリアとします。
- 判定は操作後のステージ状態に基づいて行い、同一の状態に対して結果が変化しないようにします。
- クリア後は完了状態へ移行し、プレイ中の操作を受け付けません。
- 達成条件を満たしていない場合は、プレイ中の状態を継続します。

達成条件が複数あるステージでは、すべてを満たす必要があるか、いずれかを満たせばよいかをステージ仕様に明記します。

## 結果表示

結果画面では、プレイヤーが今回の試行が成功したかを判断できる表示を行います。成功時には少なくともクリアしたことを示し、再挑戦または次の操作へ進む選択肢を提示します。

スコア、所要時間、評価ランクなどを表示する場合は、算出条件と表示対象を別途定義します。値を算出しない場合は、未設定の指標を画面に表示しません。

## 次の操作

結果画面からの遷移先は、[プレイの進行](3-2-play-progression.md)と整合させます。次のステージが存在しない場合は、存在しないステージへ遷移させず、ステージ選択またはゲーム終了へ案内します。

## 二重判定の防止

クリア判定後に同じ操作やイベントを複数回受け取っても、結果画面を重ねて表示したり、進行状況を複数回更新したりしないようにします。

**要確認**

- スコア、タイム、評価ランクの有無と算出方法
- クリア演出と結果画面の表示内容
- クリア状況を保存・更新するタイミング
